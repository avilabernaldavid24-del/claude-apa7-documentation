## Instrucciones de formato

1. **Encabezado:** "Referencias" centrado en negrita
2. **Márgenes:** 2.54 cm en todos los lados
3. **Fuente:** Times New Roman, 12 puntos
4. **Espaciado:** Doble espacio (2.0)
5. **Sangría francesa:** Primera línea sin sangría, líneas siguientes con 0.5 cm
6. **Alineación:** Justificada
7. **Número de página:** Esquina superior derecha
8. **Encabezado de página:** Versión corta del título en mayúsculas

## Orden y criterios

- [ ] Orden alfabético por primer apellido del autor
- [ ] Si mismo autor, ordenar por año (menor a mayor)
- [ ] Si mismo autor y año, agregar a, b, c después del año
- [ ] No usar números de viñetas
- [ ] Cada referencia en párrafo separado
- [ ] Doble espacio entre referencias

## Tipos de fuentes comunes

### Libros
```
Apellido, I. (Año). Título del libro. Editorial.
```

### Libros con DOI
```
Apellido, I. (Año). Título del libro. Editorial. https://doi.org/xxxxx
```

### Capítulo de libro editado
```
Apellido, I. (Año). Título del capítulo. En I. Apellido (Ed.), Título del libro (pp. X-X). Editorial.
```

### Artículos de revista
```
Apellido, I. (Año). Título del artículo. Nombre de la Revista, Volumen(Número), X-X. https://doi.org/xxxxx
```

### Sitios web
```
Apellido, I. (Año). Título de la página. Recuperado de https://www.ejemplo.com
```

### Tesis
```
Apellido, I. (Año). Título de la tesis [Tesis de maestría/doctorado, Universidad]. https://doi.org/xxxxx
```

### Periódicos
```
Apellido, I. (Año, Mes Día). Título del artículo. Nombre del Periódico, X-X.
```

### Videos
```
Apellido, I. (Año). Título del video [Video]. Plataforma. https://www.ejemplo.com
```

### Redes sociales
```
Apellido, I. [@usuario]. (Año, Mes Día). Contenido del mensaje [Estado de red social]. Recuperado de https://www.ejemplo.com
```

## Notas importantes

- Utilizar cursiva (*texto*) para títulos de libros y revistas
- El DOI va después del período final de la referencia
- Si no hay DOI disponible, usar URL completa
- Año entre paréntesis después del autor
- NO incluir "Recuperado de" si se proporciona DOI
- Verificar formato según tipo de fuente
