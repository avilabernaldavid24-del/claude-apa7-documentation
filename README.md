# Claude APA 7ª Edición - Documentación

Repositorio con configuración y prompts para que Claude genere documentos siguiendo normas **APA 7ª edición**.

- `prompts/` - Prompts base para diferentes tipos de documentos
- `normas/` - Guía completa de normas APA 7ª edición
- `plantillas/` - Plantillas de documentos en formato APA
- `ejemplos/` - Ejemplos de documentos completamente formateados

## Cómo usar

1. Selecciona el tipo de documento que necesitas (ensayo, artículo, trabajo de investigación, etc.)
2. Usa el prompt correspondiente de la carpeta `prompts/`
3. Pega el prompt en Claude junto con tu contenido
4. Claude generará el documento siguiendo las normas APA 7ª

##  Tipos de documentos disponibles

- Ensayos académicos
- Artículos de investigación
- Trabajos de grado
- Reportes técnicos
- Reseñas bibliográficas
- Propuestas de investigación
